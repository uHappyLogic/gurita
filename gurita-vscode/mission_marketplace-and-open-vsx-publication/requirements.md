# Marketplace and Open VSX publication

## Goal

Publish Gurita for VS Code as `uhappylogic.gurita-vscode` on the Visual Studio Marketplace and on Open VSX, so it installs from the Extensions view of VS Code and of the forks that read Open VSX; the mission ends with the extension live on both. The steps only the maintainer can take, creating the publisher and the namespace and issuing the tokens, are the mission's first tasks, and the package gets what a public listing needs: a user-facing README, an icon, and listing metadata. Releasing a version of the extension becomes a maintainer-only skill of its own beside `/release-plugin`, through which the first publication is made, and the check comparing the installed plugin's version with the packaged one stays as it is.
