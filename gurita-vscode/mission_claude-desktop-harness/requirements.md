# Claude Desktop harness

## Goal

Add Claude Desktop to Gurita for VS Code as a fourth harness beside Claude Code, Antigravity, and Codex, listed under Harnesses in the Settings window and selectable only for an action that is a single interactive line, so that a person who needs Desktop's visual and sound artifacts (samples for the alternatives of an open question, for example) can open that action as a session in Claude Desktop's Code tab on the project's folder instead of in a VS Code terminal; sending is fire-and-forget, with no run tracked, and chains and headless lines stay in the terminal. The mission opens with a hands-on check of what Claude Desktop accepts from outside: a session with the prompt prefilled is enough, model, effort, and permission mode are carried only where Desktop takes them, and if no prompt can be passed the mission stops there and records why. It is done when the feature, its tests, and gurita-vscode/USAGE.md are in place, and it makes no extension release.
